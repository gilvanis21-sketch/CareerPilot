# Guide utilisateur — CareerPilot

## 1. Premiers pas
1. **Inscription** : e-mail, mot de passe (10 caractères min., majuscule, minuscule, chiffre) et case de consentement RGPD.
2. **Mon CV** : importez un PDF ou DOCX (5 Mo max). L'analyse est locale et ne retient que ce qui est écrit dans le CV.
3. **Mon profil** : vérifiez et complétez prénom, formation, année (B1–B4), compétences, localisations, **objectif (stage ou alternance)**. C'est vous la référence.

## 2. Trouver des offres
- **Offres** → « Actualiser les offres ». Les offres sont classées par **score de compatibilité /100** : il mesure l'adéquation avec votre profil, **pas vos chances d'être recruté**.
- Filtres : mots-clés, lieu, entreprise, compétence, contrat, date, favoris.
- Ouvrez une offre pour voir les compétences correspondantes/manquantes et l'explication.
- Badge « fictive » : offre de démonstration, ne postulez pas.
- LinkedIn : lien de recherche préremplie, vous cherchez vous-même (aucune collecte automatique).

## 3. Postuler
1. « Préparer ma candidature » crée un **brouillon** (rien n'est envoyé).
2. « Générer le message » → relisez, modifiez, enregistrez. Un avertissement apparaît si une technologie citée n'est pas dans votre profil.
3. Saisissez l'**adresse du destinataire** (jamais devinée par l'outil) ; sans adresse, utilisez « Copier le message » et postulez sur le site.
4. **Valider** puis cocher la confirmation puis « Envoyer ». Toute modification annule la validation.
- **Candidature spontanée** : entreprise, secteur, e-mail de contact, compétences 360 (suggestion selon le secteur), option stage de 2 mois pouvant être non rémunéré.

## 4. Connecter sa messagerie (Paramètres)
Cliquez sur **Se connecter avec Google** ou **Se connecter avec Microsoft** (Paramètres → Messagerie d'envoi) : vous autorisez uniquement l'envoi, sans saisir de mot de passe (voir `docs/oauth-messagerie.md`). Autre méthode pour Gmail : validation en 2 étapes, **mot de passe d'application** (compte Google → Sécurité), jamais votre mot de passe habituel.
Plafond quotidien et jours de relance sont réglables (par défaut J+7 et J+15).

## 5. Suivre
« Candidatures » liste les statuts (brouillon, à valider, envoyée, en attente, entretien, refusée, acceptée, relance nécessaire). Mettez le statut à jour quand vous recevez une réponse. Le tableau de bord résume vos taux de réponse et d'entretien.

## 6. Vos données
Paramètres : export JSON complet, suppression définitive du compte, consentement à l'envoi de votre profil à une IA hébergée (désactivé par défaut ; vos nom et coordonnées sont masqués avant envoi).
